# The question decision

A worker executes what the handoff, its plan and the frozen acceptance explicitly authorize.
Anything else — implementation shape, file layout, naming, test selection, fixtures, logging,
documentation wording, epic splitting (a layer of one change is not a split), acceptance
derivation or change, and scope change — is a question to the director.

The director decides what it can, records the decision, and releases the card. It answers
every decidable item and escalates only the items the decision map leaves to the human; the
release, not a note alone, ends the question. If the matter may be E1–E5 or a reserved matter,
read `escalation.md` before deciding.

One round is one question per card. The worker records the whole round in one question and
waits; the director answers every decidable item and escalates only what the map reserves; the
worker judges whether the round is complete and asks the next round as a new question. Never
spread one round across several questions. The asker's request shape is in `rounds.md`.
