# The routing decision

An unowned card is the route decision: assign exactly one accountable role from the routing
table the board supplies. A work shape the table does not describe goes to the **Worker** role;
never invent a role name. The card's assignee still selects the executing role — this table
routes, it never decides. An already-assigned card is not yours to re-route; leave a fresh or
ambiguous card for its creator.
